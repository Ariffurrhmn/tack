# Features

## MVP

- Borderless, always-on-top note windows
- Text notes
- Position, size, and content saved to SQLite and restored after restart
- Note colors
- Close and hide

## Differentiator

- Custom windows: a window can hold an image, a GIF, or a Markdown file
- Stickers

## Next

- Snapping to each other and to screen edges
- Resizing
- Saved styles (fonts, colors)
- Hide-until a date/time, or a recurring wake-up, as a reminder
- Alarms
- Text or image content
- Unicode and right-to-left text

## Later / maybe

- Attach a note to an application, site, document, or folder so it shows only when that is on screen (needs OS-specific window tracking)
- Hierarchical sharing / friends

## Cut for now

- Network transfer
- Email transfer
- Group Policy
- Public API
